Here is the exact, step-by-step algorithm for the Qwen3-Next / Qwen3.5-MoE **Gated DeltaNet** recurrent decode pass. It is specified mathematically and programmatically, matched against the authoritative FLA (`flash-linear-attention`) `fused_recurrent_gated_delta_rule` and `gated_deltanet.py` implementations.

### 1. `qkv` Projection, Slicing, and Reshaping
First, apply the linear projection for `qkv`:
```python
qkv_unconv = in_proj_qkv(x)  # Shape: [8192]
```
*(Wait to slice until after the convolution and activation, per FLA's `dynamic_conv1d` pattern for GDN).*

**Normalization (L2):** 
Yes! Both queries and keys are strictly **L2-normalized** per-head across the 128-dim head size using `rsqrt(sum(x^2)+1e-6)`. HF then applies `scale=1/sqrt(key_head_dim)` to the normalized query only.

### 2. The Short Convolution
The depthwise causal conv (`conv1d.weight`: `[8192, 1, 4]`) is applied to the **concatenated `qkv` [8192]** *before* the head split. You must maintain a ring buffer of the past 3 inputs.

Given `X_t = qkv_unconv`, and ring buffer `[X_{t-3}, X_{t-2}, X_{t-1}]`:
```python
# PyTorch cross-correlation maps weight index 3 to the newest timestep
qkv_conv = (X_{t-3} * weight[:, 0, 0] + 
            X_{t-2} * weight[:, 0, 1] + 
            X_{t-1} * weight[:, 0, 2] + 
            X_t     * weight[:, 0, 3])  # Shape: [8192]

# Apply SiLU activation immediately after convolution
qkv_silu = silu(qkv_conv)
```
Now, split `qkv_silu` into `q`, `k`, `v`:
*   `q` = `qkv_silu[0:2048]` $\rightarrow$ reshape to `[16, 128]` $\rightarrow$ **apply L2 norm and query scale:** $q_h = \frac{q_h}{\sqrt{\sum q_h^2 + 10^{-6}}} \cdot \frac{1}{\sqrt{128}}$
*   `k` = `qkv_silu[2048:4096]` $\rightarrow$ reshape to `[16, 128]` $\rightarrow$ **apply L2 norm:** $k_h = \frac{k_h}{\sqrt{\sum k_h^2 + 10^{-6}}}$
*   `v` = `qkv_silu[4096:8192]` $\rightarrow$ reshape to `[32, 128]`

### 3. The Decay Gate $a$ (per v-head)
The decay controls how much of the recurrent state is forgotten. The negative formulation causes $a \in (0, 1)$.
```python
in_a = in_proj_a(x)  # Shape: [32]
# Exact formula mapping A_log and dt_bias:
g = -exp(A_log) * softplus(in_a + dt_bias)  # Shape: [32]
a = exp(g)                                  # Shape: [32]
```

### 4. The Write Gate $b$ (per v-head)
The beta/write gate controls how much of the new key/value interaction is written to the state.
```python
in_b = in_proj_b(x)    # Shape: [32]
b = sigmoid(in_b)      # Shape: [32]
```

### 5. The Recurrent STATE Update (Gated Delta Rule)
**GQA Mapping:** You have 32 V-heads and 16 K/Q-heads. For each V-head $i \in [0, 31]$, use K/Q-head $j = \lfloor i / 2 \rfloor$.

Let the state $S_{t-1}$ be formatted as `[key_dim=128, value_dim=128]`, making $S \in \mathbb{R}^{K \times V}$.
For each V-head $i$, given column vectors $k \in \mathbb{R}^{128 \times 1}$ and $v \in \mathbb{R}^{128 \times 1}$:
$$S_t = a \cdot S_{t-1} + b \cdot k \otimes \big(v - a \cdot S_{t-1}^T k\big)$$

*Note the exact dependency inside the delta term:* The state is multiplied by $a$ **inside** the parenthesis before being multiplied by $k$. This is the "exact gated delta rule" necessary for equivalence with the parallel chunked form.

*In pure tensor/Rust ops (per v-head):*
`state_k = S_{t-1}^T @ k`  *(shape: 128)*
`delta_v = v - (a * state_k)` *(shape: 128)*
`S_t = a * S_{t-1} + b * outer_product(k, delta_v)` *(shape: 128x128)*

### 6. Readout and Output Gating
Readout the output $o_i$ for each V-head $i$:
$$o_i = S_t^T q$$
*(If $S_t$ is $K \times V$, then $S_t^T$ is $V \times K$, and multiplying by $q$ ($K \times 1$) yields $V \times 1$ -> shape `[128]`)*.

Concatenate all 32 V-heads to form a flat output vector `o` of shape `[4096]`.

**Gated RMSNorm Order:**
Compute the output gate: `z = in_proj_z(x)` (Shape `[4096]`).
The normalization applies **before** the element-wise SiLU gating, and it is computed **per value-head**.
1. Reshape `o` and `z` to `[32, 128]`.
2. For each head $i$, compute standard RMSNorm across the `128` feature dimension, multiplied by the broadcasted `norm.weight` parameter (which is shape `[128]`):
   $$o_{\text{norm}, i} = \frac{o_i}{\sqrt{\text{mean}(o_i^2) + \epsilon}} \odot \text{norm.weight}$$
3. Gate the output: 
   $$o_{\text{gated}, i} = o_{\text{norm}, i} \odot \text{silu}(z_i)$$
4. Flatten back to `[4096]` and apply `out_proj(o_gated)` to get the final `[2048]` result.

### 7. Decode STATE to Persist (KV-Cache Equivalent)
Your recurrent state cache across tokens must maintain:
1. **Delta State `$S$`**: Tensor of shape `[32, 128, 128]`. Strictly maintain this in **`f32`** to avoid catastrophic precision loss during accumulation.
2. **Conv Ring Buffer**: Tensor of shape `[3, 8192]` (or a sliding window of the last 3 unmodified `qkv` vectors). Maintain this in the model's native dtype (e.g., `bf16`/`f32`).

### 8. Final Checklist on Normalizations/Scalings
*   **$q/k$ L2 Norm**: Required. Computed along the `head_dim` (128).
*   **Scaling**: `scale=1/sqrt(K)`, where `K = key_head_dim = 128`, so `scale = 0.08838834764831845`. Apply this to `q` after L2 normalization; do not scale `k`.
*   **Conv Bias**: `conv_bias = False` (the projection only has weights).
*   **Decay Base**: Ensure you use `softplus` on the `dt_bias`, not just a raw addition. The exact `-exp(A_log) * softplus(...)` translates smoothly into a $(0,1)$ exponential decay.
