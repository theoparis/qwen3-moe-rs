## Hardening required before L2B / GRPO reuse (union of all three voices) → P0.2-harden

1. **`decode_n` cumulative-`pos` overrun (Gemini Rank-1 100% / Codex F7 / Opus #3) — MUST FIX.** `decode_n`
   asserts `n <= max_new` per-call but not against the live `pos`; a second `decode_n` (or streaming
   `decode_n(1)` in a loop) advances `pos` past `prompt_len+max_new` → the Add-scatter writes OOB / accumulates
   over non-zero columns → **silent device-memory corruption.** Fix: `decode_n` asserts `pos == prompt_len` on
   entry OR resets internally.
2. **Capture-safe RNG + fail-closed `step` guard (Opus #5 — the single biggest risk).** A sampling consumer
   wiring `Tensor::random`/`device_select_tokens` into `step` captures a **frozen host seed → identical token
   every replay, silently** (all asserts green). Land a **device-counter RNG threaded through `DecodeState`**
   (advanced in-graph like `pos`; the P3 `cudagraph_p3_rng_bench` device-seed pattern), + a **loud capture-time
   guard/doc** that `step` must contain no host-seeded RNG and no host sync (`into_data`/`to_vec`/`into_scalar`).
3. **Snapshot/pin the immutable surface (Opus #1 / Codex F3).** `state.pad`, the `sd` struct (freqs, arange,
   expert stacks), and model weights + `lm_head` are baked into the graph but NOT snapshotted — safe only by
   construction. Document (and ideally assert) that the model + `sd` must be pinned for the graph's lifetime;
   add `pad` to the snapshot.
4. **Reusability extensions:** per-step **logits history** buffer + device-tensor accessor (GRPO needs logp/KL;
   harness overwrites `last` in place); **variable prompt length** + **new-tokens-only return** (vLLM); an
   **EOS early-stop / streaming** replay hook (decode_n ignores `finished`).
5. **Consumer-facing `warmup` default ≥ 8, not 3** (Opus #2 — 3 may be marginal for 48-layer autotune commit).
